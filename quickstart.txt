- Encoding / UTF-8 / emoji output on Windows:

  Safe non-emoji fallbacks are used where possible. The A1 output itself is mostly ASCII + a few symbols.

- Tesseract OCR for real (non-sim) vision:
  `pip install -r requirements.txt` only installs the Python pytesseract wrapper.
  For actual card reading you must install the Tesseract binary separately:
    Download from https://github.com/UB-Mannheim/tesseract/wiki (Windows installer).
    Add the install folder (containing tesseract.exe) to your system PATH environment variable.
  Restart terminal after PATH change.
  Without the binary: vision parse falls back to cv2 rect detection + optional templates (low conf on graphical cards); --simulate-vision still works 100% for demo.
  Tip: run `python -c "import pytesseract; print(pytesseract.get_tesseract_version())"` to verify.
